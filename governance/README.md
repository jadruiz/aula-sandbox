# Governance — aula-sandbox

Decisiones de arquitectura en `decisions/` como `ADR-NNN-tema.md`. Las autoridades humanas
son las del workspace (`../WORKSPACE_PLAN.md`): seguridad revisa cualquier cambio de
frontera (montajes, puertos, credenciales); dirección académica revisa qué herramientas
entran o salen de la imagen.
